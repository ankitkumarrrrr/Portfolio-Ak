## TimescaleDB for Financial Time-Series

PostgreSQL + TimescaleDB is the right choice here. Hypertables partition automatically by time, and continuous aggregates pre-compute rollups.

```sql
-- Create hypertable for raw ticks
CREATE TABLE ticks (
    time        TIMESTAMPTZ       NOT NULL,
    symbol      TEXT              NOT NULL,
    price       DOUBLE PRECISION  NOT NULL,
    volume      DOUBLE PRECISION  NOT NULL,
    bid         DOUBLE PRECISION,
    ask         DOUBLE PRECISION
);

SELECT create_hypertable('ticks', 'time', chunk_time_interval => INTERVAL '1 day');

-- Continuous aggregate for 1-minute candles
CREATE MATERIALIZED VIEW candles_1m
WITH (timescaledb.continuous) AS
SELECT time_bucket('1 minute', time) AS bucket,
       symbol,
       FIRST(price, time) AS open,
       MAX(price) AS high,
       MIN(price) AS low,
       LAST(price, time) AS close,
       SUM(volume) AS volume
FROM ticks
GROUP BY bucket, symbol;

-- Refresh policy: keep last 2 hours real-time, rest compressed
ADD CONTINUOUS AGGREGATE POLICY candles_1m
START INTERVAL '3 hours', END INTERVAL '1 hour';
```

**Compression policies** save 90%+ storage on raw ticks:

```sql
ALTER TABLE ticks SET (
    timescaledb.compress,
    timescaledb.compress_segmentby = 'symbol'
);

SELECT add_compression_policy('ticks', INTERVAL '7 days');
```

## Indicator Library (30+ Indicators)

Vectorized Pandas/NumPy implementations — no TA-Lib dependency for deployment simplicity.

```python
# indicators/momentum.py
import pandas as pd
import numpy as np

def rsi(series: pd.Series, period: int = 14) -> pd.Series:
    """Relative Strength Index"""
    delta = series.diff()
    gain = (delta.where(delta > 0, 0)).rolling(period).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(period).mean()
    rs = gain / loss.replace(0, np.nan)
    return 100 - (100 / (1 + rs))

def macd(series: pd.Series, fast: int = 12, slow: int = 26, signal: int = 9) -> tuple:
    """MACD line, signal line, histogram"""
    ema_fast = series.ewm(span=fast, adjust=False).mean()
    ema_slow = series.ewm(span=slow, adjust=False).mean()
    macd_line = ema_fast - ema_slow
    signal_line = macd_line.ewm(span=signal, adjust=False).mean()
    histogram = macd_line - signal_line
    return macd_line, signal_line, histogram

def bollinger_bands(series: pd.Series, period: int = 20, std_dev: float = 2) -> tuple:
    """Upper, middle, lower bands"""
    middle = series.rolling(period).mean()
    std = series.rolling(period).std()
    upper = middle + std_dev * std
    lower = middle - std_dev * std
    return upper, middle, lower
```

**Performance:** 30-plus indicators on 1M rows computes in under 200ms on a single core.

## Rule-Based Signal Engine (JSON DSL)

Traders compose signals without code:

```json
{
  "name": "Mean Reversion Long",
  "symbol": "BTC-USD",
  "timeframe": "1h",
  "conditions": {
    "all": [
      { "indicator": "rsi", "params": { "period": 14 }, "operator": "<", "value": 30 },
      { "indicator": "bb_lower", "params": { "period": 20, "std_dev": 2 }, "operator": ">", "value": "close" },
      { "indicator": "volume_ratio", "params": { "period": 20 }, "operator": ">", "value": 1.5 }
    ]
  },
  "exit": {
    "any": [
      { "indicator": "rsi", "params": { "period": 14 }, "operator": ">", "value": 70 },
      { "indicator": "bb_upper", "params": { "period": 20, "std_dev": 2 }, "operator": "<", "value": "close" }
    ]
  }
}
```

The engine evaluates this on every new candle:

```python
# engine/evaluator.py
class SignalEngine:
    def __init__(self, rule: dict):
        self.rule = rule
        self.indicator_cache = {}
    
    def evaluate(self, candles: pd.DataFrame) -> Signal | None:
        # Compute all indicators once
        indicators = self._compute_all(candles)
        
        # Check entry conditions
        if self._check_conditions(self.rule['conditions'], indicators):
            return Signal(type='entry', direction='long', ...)
        
        # Check exit conditions
        if self._check_conditions(self.rule['exit'], indicators):
            return Signal(type='exit', ...)
        
        return None
```

## WebSocket Ingestion with Gap Detection

Exchanges drop messages. We handle this gracefully:

```python
# ingestion/websocket.py
import asyncio
import websockets
import json

class ExchangeFeed:
    def __init__(self, url: str, symbols: list[str]):
        self.url = url
        self.symbols = symbols
        self.sequence_ids = {s: 0 for s in symbols}
        self.message_queue = asyncio.Queue()
        self.gap_detected = asyncio.Event()
    
    async def connect(self):
        async with websockets.connect(self.url) as ws:
            await ws.send(json.dumps({
                'method': 'SUBSCRIBE',
                'params': [f'{s}@trade' for s in self.symbols],
                'id': 1
            }))
            
            async for message in ws:
                data = json.loads(message)
                await self._handle_message(data)
    
    async def _handle_message(self, data: dict):
        symbol = data['s']
        seq = data.get('E', 0)  # Event time as proxy for sequence
        
        expected = self.sequence_ids[symbol] + 1
        if seq > expected:
            # Gap detected!
            self.gap_detected.set()
            # Request replay or log for backfill
            await self._request_gap_fill(symbol, expected, seq)
        
        self.sequence_ids[symbol] = seq
        await self.message_queue.put(self._normalize(data))
```

## Backtesting Without Lookahead Bias

Event-driven simulator with strict timestamp ordering:

```python
# backtest/simulator.py
class BacktestSimulator:
    def __init__(self, initial_capital: float = 100000):
        self.capital = initial_capital
        self.positions = {}
        self.trades = []
        self.equity_curve = []
    
    def run(self, candles: pd.DataFrame, signals: list[Signal]):
        """Process candles chronologically, execute signals at NEXT candle open"""
        signal_idx = 0
        
        for i, candle in candles.iterrows():
            # 1. Update equity with current prices
            self._update_equity(candle)
            
            # 2. Execute signals FROM PREVIOUS candle (no lookahead)
            while signal_idx < len(signals) and signals[signal_idx].timestamp <= candle.name:
                signal = signals[signal_idx]
                self._execute_signal(signal, candle)  # Uses NEXT candle's open
                signal_idx += 1
            
            self.equity_curve.append({
                'time': candle.name,
                'equity': self.capital + self._unrealized_pnl(candle)
            })
```

## Key Learnings

1. **Data quality > model complexity** — A simple momentum strategy on clean, validated data outperforms complex ML on noisy feeds.
2. **Observability is non-negotiable** — Metrics, alerts, and replay capability are requirements, not nice-to-haves.
3. **TimescaleDB continuous aggregates are a force multiplier** — Pre-computed rollups make dashboard queries instant.
4. **Backtesting honesty is hard** — Event-driven simulation with strict "next candle open" execution is the only way to avoid fooling yourself.
